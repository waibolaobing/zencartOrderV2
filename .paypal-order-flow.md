## Phase 2: User Payment at PayPal

**Mechanism**: Server-side redirect (HTTP 302)
**PayPal URL**: `https://www.sandbox.paypal.com/checkoutnow?cmd=_express-checkout&token={PAYPAL_ORDER_ID}&useraction=continue`
**Parameters**:
- `cmd=_express-checkout` - Classic Express Checkout command
- `token={PAYPAL_ORDER_ID}` - PayPal order ID (e.g., "EC-XXXXXXXXXXXXX" or REST v2 ID)
- `useraction=continue` - Show "Review Payment" button (vs `commit` for "Pay Now")

**User Actions at PayPal**:
1. Logs in with PayPal credentials
2. Reviews order details
3. Selects funding source (PayPal balance, bank account, credit card, Pay Later)
4. Clicks "Continue" or "Pay Now" button
5. PayPal redirects back to store's return URL
