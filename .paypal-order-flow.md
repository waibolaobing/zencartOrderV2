## Phase 1: Payment Initiation (Create Order)

**Entry Point**: `code/ipn_main_handler.php:15` - Express Checkout handler route

**Flow Trace**:

1. **User clicks PayPal Express Checkout button** on shopping cart page
   - Button location: `/code/includes/modules/payment/paypal/tpl_ec_button.php:62`

2. **Call**: `ipn_main_handler.php:15` - Express Checkout routing
   - **Does**: Checks if `$_GET['type'] == 'ec'` to identify EC request
   - Loads `application_top.php` for Zen Cart initialization
   - Validates cart (not empty, stock check, cart ID validation)
   - Initializes payment module: `$payment_modules = new payment('paypalwpp')`
   - Sets session payment method: `$_SESSION['payment'] = 'paypalwpp'`

3. **Call**: `ipn_main_handler.php:71-75` - Check for existing token
   - **Does**: Checks if `$_SESSION['paypal_ec_token']` exists
   - If no token → Call `ec_step1()` (Create Order phase)
   - If token exists → Call `ec_step2()` (Return phase - covered in Phase 3)

4. **Call**: `paypalwpp.php:1517` - `paypalwpp::ec_step1()`
   - **Does**:
     - Validates cart (not empty, cart validation)
     - Loads order object: `$order = new order()`
     - Initializes shipping module: `$shipping_modules = new shipping($_SESSION['shipping'])`
     - Loads order total modules: `$order_total_modules = new order_total()`

5. **Call**: `paypalwpp.php:1542` - Initialize PayPal API client
   - **Does**: `$doPayPal = $this->paypal_init()`

6. **Call**: `paypalwpp.php:1546` - Build order line item details
   - **Does**: `$options = $this->getLineItemDetails($this->selectCurrency())`
   - Prepares product details, amounts, tax, shipping for PayPal order

7. **Call**: `paypal_rest_v2.php:55` - `SetExpressCheckout()`
   - **Does**:
     - Gets OAuth access token: `$token = $this->config->getAccessToken()`
     - Builds PayPal order data: `$order_data = $this->buildOrderData($options, $returnUrl, $cancelUrl)`
     - **Calls PayPal API**: `POST /v2/checkout/orders`
       - URL: `$this->config->getBaseUrl() . '/v2/checkout/orders'`
       - Headers: `Authorization: Bearer {token}`, `Content-Type: application/json`
       - Body: JSON order data (items, amounts, shipping, URLs)
     - Receives response with PayPal Order ID
     - Converts REST v2 response to NVP format: `return $this->convertToNVPFormat('SetExpressCheckout', $response)`

8. **Call**: `paypalwpp.php:1726` - Store token in session
   - **Does**: `$_SESSION['paypal_ec_token'] = preg_replace('/[^0-9.A-Z\-]/', '', urldecode($response['TOKEN']))`
   - Sanitizes and stores PayPal Order ID (token)

9. **Returns/Redirects**: HTTP redirect to PayPal
   - **Redirects to**: `$this->getPayPalLoginServer() . "?cmd=_express-checkout&token=" . $_SESSION['paypal_ec_token']`
   - **Example URL**: `https://www.sandbox.paypal.com/checkoutnow/?cmd=_express-checkout&token=52W83658UU098511C`
   - **Return URL sent to PayPal**: `http://localhost:8087/ipn_main_handler.php?type=ec` (will be called with `?token=...&PayerID=...`)
   - **Cancel URL sent to PayPal**: Store homepage or shopping cart

**Preparation Work Summary**:
- **API calls**: 1 PayPal API call (`POST /v2/checkout/orders` to create order)
- **State set**:
  - `$_SESSION['payment']` = `'paypalwpp'`
  - `$_SESSION['paypal_ec_token']` = PayPal Order ID
  - `$_SESSION['cart']` object validated
  - `$_SESSION['cartID']` validated for session integrity
- **Data stored**: None (all state in PHP sessions)
- **Validation performed**:
  - Cart not empty check
  - Stock availability check
  - Cart ID validation (prevents session manipulation)
  - Order total calculation and validation

**Guest Checkout**: Supported
- **Evidence**: `paypalwpp.php:2116-2198` shows automatic account creation for new customers
- **Authentication check**: None in ec_step1() - flow supports guest users
- **Note**: Guest users are automatically created as Zen Cart accounts during ec_step2()

**Form Analysis**:
- **Is this an async API endpoint?**: No
- **Is it a page handler?**: Yes (PHP file that redirects)
- **Can it be reused for SDK v6?**: No - this is a page handler that redirects, not an API endpoint
- **For SDK v6**: Would need to create new async API endpoint that:
  1. Replicates all preparation work from ec_step1()
  2. Calls same PayPal REST v2 API (`POST /v2/checkout/orders`)
  3. Returns JSON: `{"orderId": "PAYPAL_ORDER_ID", "amount": "XX.XX", "currencyCode": "USD"}`
  4. Sets same session state for compatibility with Phase 3 flow

## Phase 2: User Payment at PayPal

**Mechanism**: Browser redirect to PayPal hosted checkout page

**PayPal URL**: `https://www.sandbox.paypal.com/checkoutnow/?cmd=_express-checkout&token={PAYPAL_ORDER_ID}&useraction=continue`

**Parameters Passed**:
- `cmd=_express-checkout` - Legacy command parameter (maintained for compatibility)
- `token={PAYPAL_ORDER_ID}` - PayPal Order ID created in Phase 1
- `useraction=continue` - Indicates continue/commit action
- Note: Modern REST v2 tokens do not have "EC-" prefix (legacy NVP tokens do)

**User Actions at PayPal**:
1. User logs into PayPal account (or creates new account)
2. User reviews payment details
3. User selects funding source (balance, bank account, credit card, Pay Later)
4. User confirms payment

**Return from PayPal**:
- **Return URL**: `http://localhost:8087/ipn_main_handler.php?type=ec`
- **Return Parameters**:
  - `token={PAYPAL_ORDER_ID}` - Same order ID from Phase 1
  - `PayerID={PAYER_ID}` - PayPal customer's Payer ID (e.g., "ABCD1234XYZ")
- **Cancel URL**: `http://localhost:8087/index.php?main_page=shopping_cart` (if user cancels)

## Integration Strategy for PayPal Web SDK v6

Based on the flow analysis above, here's how to integrate PayPal Web SDK v6:

### Create Order API Implementation

**Reusability Assessment**:
- **Can reuse existing create order function?**: No
- **Reason**: Existing `ec_step1()` is a page handler that redirects to PayPal, not an async API endpoint that returns JSON

**Recommended Approach**: **Create new async API endpoint**

**Why New API is Needed**:
1. SDK v6 `createOrder()` callback requires async API that returns JSON
2. Existing `ec_step1()` is a page handler that redirects (not compatible)
3. Must replicate ALL preparation work from Phase 1 to ensure Phase 3 works correctly

**New API Implementation Requirements**:

**Critical**: This Create Order API must do EVERYTHING Phase 1 (ec_step1) does:
- ✅ Validate cart (not empty, stock check)
- ✅ Load order object and calculate totals
- ✅ Load shipping and order total modules
- ✅ Process order totals
- ✅ Build line item details
- ✅ Call PayPal REST v2 API (`POST /v2/checkout/orders`)
- ✅ Set session state:
  - `$_SESSION['payment']` = `'paypalwpp'`
  - `$_SESSION['paypal_ec_token']` = PayPal Order ID
  - `$_SESSION['cartID']` validation
- ✅ Return JSON response for SDK v6

**API Endpoint Specification**:
- **Route**: `POST /api/paypal/create-order` (new endpoint)
- **Request**: None (uses session cart)
- **Response**:
  ```json
  {
    "orderId": "PAYPAL_ORDER_ID",
    "amount": "99.99",
    "currencyCode": "USD"
  }
  ```
- **Error Response**:
  ```json
  {
    "error": "Error message",
    "code": "ERROR_CODE"
  }
  ```

**Implementation Location**:
- **Recommended file**: Create new file: `code/includes/modules/payment/paypal/paypal_api.php`
- **Or add to**: `code/ipn_main_handler.php` with new route parameter (e.g., `?type=ec&action=create_api`)

**Code Structure** (extracted from paypalwpp.php:1517-1730):
```php
<?php
/**
 * PayPal Create Order API Endpoint for SDK v6
 * Call: POST /api/paypal/create-order
 */
header('Content-Type: application/json');

require_once('includes/application_top.php');

// Validate cart
if ($_SESSION['cart']->count_contents() == 0) {
    echo json_encode(['error' => 'Cart is empty']);
    exit;
}

// Stock check
if (STOCK_CHECK == 'true' && STOCK_ALLOW_CHECKOUT != 'true') {
    $products = $_SESSION['cart']->get_products();
    foreach ($products as $product) {
        $qtyAvailable = zen_get_products_stock($product['id']);
        if ($qtyAvailable - $product['quantity'] < 0) {
            echo json_encode(['error' => 'Out of stock']);
            exit;
        }
    }
}

// Init order object
require(DIR_WS_CLASSES . 'order.php');
$order = new order;

// Load shipping module
require(DIR_WS_CLASSES . 'shipping.php');
$shipping_modules = new shipping($_SESSION['shipping']);

// Load order total modules
require(DIR_WS_CLASSES . 'order_total.php');
$order_total_modules = new order_total;
$order_totals = $order_total_modules->pre_confirmation_check();
$order_totals = $order_total_modules->process();

// Init PayPal client
require(DIR_WS_MODULES . 'payment/paypalwpp.php');
$paypalwpp = new paypalwpp();
$doPayPal = $paypalwpp->paypal_init();

// Build order details
$options = $paypalwpp->getLineItemDetails($paypalwpp->selectCurrency());

// Set return and cancel URLs for SDK v6
$returnUrl = zen_href_link('ipn_main_handler.php', 'type=ec', 'SSL');
$cancelUrl = zen_href_link(FILENAME_SHOPPING_CART, '', 'SSL');

// Call PayPal API to create order
$response = $doPayPal->SetExpressCheckout($returnUrl, $cancelUrl, $options);

// Check for errors
if ($response['ACK'] == 'Failure') {
    echo json_encode([
        'error' => $response['L_LONGMESSAGE0'],
        'code' => $response['L_ERRORCODE0']
    ]);
    exit;
}

// Store token in session (for Phase 3 compatibility)
$_SESSION['paypal_ec_token'] = preg_replace('/[^0-9.A-Z\-]/', '', urldecode($response['TOKEN']));
$_SESSION['payment'] = 'paypalwpp';

// Extract amount from response
$amount = isset($response['PAYMENTREQUEST_0_AMT']) ? $response['PAYMENTREQUEST_0_AMT'] : '0.00';
$currency = isset($response['PAYMENTREQUEST_0_CURRENCYCODE']) ? $response['PAYMENTREQUEST_0_CURRENCYCODE'] : 'USD';

// Return JSON response for SDK v6
echo json_encode([
    'orderId' => $response['TOKEN'],
    'amount' => $amount,
    'currencyCode' => $currency
]);
?>
```

**Guest Checkout Reminder**:
- **Do NOT add authentication checks** in Create Order API
- Must support guest users (Phase 1 analysis shows this is supported)
- Do not check if user is logged in
- Let Phase 3 (ec_step2) handle account creation automatically

### Payment Completion Integration

**Reusability Assessment**:

**Can SDK v6 reuse this payment completion flow?**: **Yes** (with specific integration method)

**Reasoning**:
- **Entry point**: `ipn_main_handler.php?type=ec` (from Phase 3, step 1)
- **Can trigger?**: **Yes** - Entry point is a page URL that accepts browser navigation
- **Required data**: PayPal Order ID (orderId) and Payer ID (payerId)
  - SDK v6 provides: ✅ `orderId` and `payerId` (camelCase with lowercase 'd')
- **Prerequisites**: Session state set by Phase 1 (token, payment method, cart validation)
  - Will be satisfied? ✅ **Yes** - Create Order API will set same sessions as Phase 1
- **Flow completes?**: ✅ **Yes** - Full flow from entry point through capture to order completion

**Conclusion**: Can reuse ✅

**Recommended Approach**:

Based on Phase 3 analysis, the entry point (`ipn_main_handler.php?type=ec`) is a page URL that accepts navigation. Therefore, **use direct redirect in onApprove**.

**Integration Method**: Direct redirect in SDK v6 `onApprove` callback

**Implementation**:

```javascript
// In shopping cart template or JS file
async onApprove({ orderId, payerId }) {
  // SDK v6 provides orderId (PayPal Order ID) and payerId (Payer ID)
  // Note: parameter names are camelCase with lowercase 'd'

  // Redirect to existing Phase 3 entry point
  // Match the URL format that Phase 3 expects (with token and PayerID)
  window.location.href = `/ipn_main_handler.php?type=ec&token=${orderId}&PayerID=${payerId}`;

  // What happens next:
  // 1. Browser navigates to ipn_main_handler.php
  // 2. Existing ec_step2() flow runs automatically
  // 3. Account creation/login happens
  // 4. User redirected to checkout_confirmation page
  // 5. User clicks "Confirm Order"
  // 6. before_process() captures payment via DoExpressCheckoutPayment()
  // 7. Order created in database
  // 8. User redirected to checkout_success page
}
```

**No new backend code needed** for payment completion - existing flow handles everything!

**Why this works**:
1. **Entry point accepts navigation**: `ipn_main_handler.php` is a page URL, not an API endpoint
2. **Multi-step flows are supported**: SDK v6 doesn't need to complete payment immediately; it just needs to trigger the flow
3. **Redirect maintains session**: Browser navigation preserves PHP sessions
4. **Existing flow works**: All the complex logic (account creation, address handling, capture) already exists and works

**What about the confirmation page?**:
- After redirect, user will see checkout_confirmation page (step 16 in Phase 3)
- User must click "Confirm Order" button to trigger capture (step 17-20 in Phase 3)
- This is the existing flow and it's fully supported
- SDK v6's job is done after the redirect - it hands off to the existing Zen Cart flow

**Alternative: If you want to skip confirmation page**:
- Would need to modify checkout_process to accept GET parameters
- More complex and changes existing user experience
- **Not recommended** - better to maintain existing UX

**Guest Checkout Reminder**:
- **Do NOT assume user is logged in** when onApprove is called
- Phase 3 flow handles guest users automatically (account creation in ec_step2_finish)
- No special handling needed - just redirect and let existing flow work

```javascript
  // SDK v6 callback parameters: { orderId, payerId } (camelCase with lowercase 'd')

  window.location.href = `/ipn_main_handler.php?type=ec&token=${orderId}&PayerID=${payerId}`;
}
```

**Entry Point**: `GET /ipn_main_handler.php?type=ec`
- Accepts URL parameters: `token` (order ID) and `PayerID` (payer ID)
- Processes complete payment flow including:
  - Retrieving order details from PayPal
  - Creating customer account (if new customer)
  - Logging in customer
  - Setting shipping/billing addresses
  - Selecting shipping method
  - Redirecting to checkout confirmation page
  - Capturing payment when user confirms order
  - Creating order in database
- Returns HTML or redirects to success page

**No new backend code needed** - existing flow handles everything through the redirect.

### Frontend Integration Guide

**Create Order**: Call `POST /api/paypal/create-order.php` when user clicks PayPal button

**Payment Completion**: Redirect to `/ipn_main_handler.php?type=ec&token={orderId}&PayerID={payerId}` in onApprove callback

**SDK v6 onApprove Parameters**: `{ orderId, payerId }` (camelCase with lowercase 'd')

**Example SDK Initialization**:
```javascript
// Get SDK instance (already initialized in paypal_sdk_v6.js)
const sdkInstance = await window.paypalSdk;

// Create payment session when SDK is ready
document.addEventListener('paypalSdkReady', async function() {
  if (sdkInstance && typeof sdkInstance.createPayLaterOneTimePaymentSession === 'function') {
    const paymentSession = sdkInstance.createPayLaterOneTimePaymentSession({
      async onApprove({ orderId, payerId }) {
        // Redirect to existing Phase 3 entry point
        window.location.href = `/ipn_main_handler.php?type=ec&token=${orderId}&PayerID=${payerId}`;
      },

      async onCancel() {
        // User cancelled - redirect to shopping cart
        window.location.href = '/index.php?main_page=shopping_cart';
      },

      onError(err) {
        // Handle errors
        console.error('PayPal payment error:', err);
        window.location.href = '/index.php?main_page=shopping_cart';
      }
    });

    // Store payment session globally for button to use
    window.paypalPaymentSession = paymentSession;
  }
});

// Create order function
async function createOrder() {
  const response = await fetch('/api/paypal/create-order.php', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json'
    }
  });

  if (!response.ok) {
    throw new Error('Failed to create PayPal order');
  }

  const data = await response.json();
```
